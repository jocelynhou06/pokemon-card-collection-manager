# Pokemon Card Collection Manager
Java application for organizing and managing personal Pokemon card collection.

## Current Features
- Add/remove cards from collection
- Quantity tracking for each card
- Can manage graded cards
- Sort cards by name or set
- Notification system upon changes in collection

## Design Patterns

- Flyweight
- Decorator
- Strategy
- Observer
- Iterator
- Template Method

## Technologies

- Java
- JUnit
